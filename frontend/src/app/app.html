4

Соберите и запустите контейнер

Запустите сборку и фоновый запуск контейнера runner:

Проверьте логи контейнера:

docker compose logs -f runner

Когда появится запись Runner connected, контейнер успешно привязан. На этой вкладке статус переключится на «В сети». Секретный токен сохранён в локальном Docker volume runner_data, значение кода в .env можно очистить.

Для OpenAI Codex:

docker compose exec runner /app/scripts/provider-login.sh codex <ID_АККАУНТА>

Откроется ссылка для входа через браузер по одноразовому коду (Device Auth).

Для Google Antigravity:

Для ChatGPT Web (Браузер):

docker compose exec runner /app/scripts/provider-login.sh chatgpt <ID_АККАУНТА>

Безопасность runner

Контейнер runner устанавливает только исходящее websocket-соединение с сайтом и не открывает внешние порты. Все токены и ключи авторизации сохраняются в изолированном Docker volume на вашем хосте.
