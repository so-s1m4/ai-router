git clone https://github.com/so-s1m4/ai-router.git

3

Create and configure the .env file

Copy the environment variables template:

cp .env.example .env

Specify the following settings in runner/.env:

# URL of your AI Router server
ROUTER_SERVER_URL={{serverOrigin()}}

# pairing code from step 1 (needed once)
ROUTER_PAIRING_CODE={{pairingCodePlaceholder()}}

4

Build and run the container

Start building and running the runner container in the background:

docker compose up --build -d

Check the container logs:

docker compose logs -f runner

When you see Runner connected, the container is successfully bound. On this tab the status will switch to “Online“. The secret token is saved in the local Docker volume runner_data, code value in .env can be cleaned.

5

Authorize provider accounts

Go to the tab “Connections“, add the desired account and assign the running runner to it. Then run the login command on your device:

For OpenAI Codex:

docker compose exec runner /app/scripts/provider-login.sh codex <ACCOUNT_ID>

A link will open to log in via a browser using a one-time code (Device Auth).

For Google Antigravity:

docker compose exec runner /app/scripts/provider-login.sh antigravity <ACCOUNT_ID>

For ChatGPT Web (Browser):

docker compose exec runner /app/scripts/provider-login.sh chatgpt <ACCOUNT_ID>
