Importing a ChatGPT session

Account: {{ vm.selectedChatGPTAccount()?.name }}

Paste the cookie value __Secure-next-auth.session-token or a full JSON array of cookies (for example, exported from the Cookie-Editor extension).

How to get a token:
  1. Open chatgpt.com and log in to your account.
  2. Open Developer Tools (F12) → tab Application (Storage) → Cookies → https://chatgpt.com.
  3. Copy the cookie value __Secure-next-auth.session-token.
